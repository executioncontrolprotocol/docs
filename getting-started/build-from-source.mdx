Build ECP (Execution Control Protocol) from source when you are changing the CLI, the host, or a plugin, or want unreleased changes. The default branch, `development`, is ahead of the latest release; check out `main` for the released code these docs describe.

## Prerequisites

- Node.js 22.12 or later
- pnpm 10 (`corepack enable` picks the pinned version)
- Git

## Clone and build

```bash
git clone https://github.com/executioncontrolprotocol/executioncontrolprotocol.git
cd executioncontrolprotocol
corepack enable
pnpm install
pnpm run build
```

Always run `pnpm install` from the repository root. The build compiles every package, regenerates the CLI manifest, and bundles the App.

## Link the `ecp` binary

```bash
cd packages/cli
pnpm link --global
cd ../..
ecp --help
```

Without linking, run the CLI directly with `node packages/cli/bin/ecp.js`.

## Install plugins from the checkout

Optional first-party plugins live under [`plugins/`](https://github.com/executioncontrolprotocol/executioncontrolprotocol/tree/main/plugins). Link one to use it without publishing:

```bash
ecp plugins link plugins/plugin-test --no-install
ecp retrieve --type capability --query echo
```

`plugins/plugin-test` provides small harness capabilities such as `@executioncontrolprotocol/test.echo`, which is handy for experiments. Linked plugins reload their schemas from source, so rebuilding a linked plugin and running `ecp host restart` picks up your changes.

## Run the examples

The repository's [`examples/`](https://github.com/executioncontrolprotocol/executioncontrolprotocol/tree/main/examples) folder holds ready-to-run executions:

```bash
ecp execute examples/echo/echo.ecp.json
ecp execute examples/transform/greet.ecp.json
ecp app examples/branch-loop/branch-loop.ecp.json
```

## Checks

```bash
pnpm run check   # build, manifests, lint, secret scan, unit, integration, e2e, and App tests
```

## Repository layout

| Path | Contents |
| ---- | -------- |
| `packages/protocol` | Types, JSON Schemas, service tokens, error catalogue |
| `packages/engine` | Executor, validation, operations, service container |
| `packages/quickjs` | Sandboxed expression and script engine (QuickJS-WASM) |
| `packages/local` | Disk storage, OS keychain secrets, plugin loading |
| `packages/formatters` | JSON and TOON output formatters |
| `packages/host` | Host process, HTTP API, supervisor |
| `packages/cli` | The `ecp` CLI |
| `packages/mcp-relay` | Stdio MCP server with the three ECP tools |
| `packages/app` | The visual App served by the host |
| `packages/plugin-sdk` | `definePlugin`, `capability`, and `ecp-plugin-manifest` |
| `plugins/plugin-*` | First-party plugins |
| `examples/` | Example executions |
