# Quickstart

Get ECP (Execution Control Protocol) running in a few minutes: install the CLI, author a Fluent workflow, bind an environment, and run.

## Prerequisites

- Node.js 22+
- npm

## Install the CLI

```bash
npm install -g @executioncontrolprotocol/cli
```

Confirm the binary:

```bash
ecp --help
```

For local monorepo development, see [Build from source](/getting-started/build-from-source).

Runnable examples live in the [core examples](https://github.com/executioncontrolprotocol/executioncontrolprotocol/tree/main/examples) tree (echo, secrets bind, encode/decode, test sessions, invoke).

## Run the echo example

From a checkout of the [ECP monorepo](https://github.com/executioncontrolprotocol/executioncontrolprotocol) (after `npm install` and `npm run build`):

```bash
ecp run examples/01-echo/workflow.ts --env examples/01-echo/environment.ts
```

Validate without executing:

```bash
ecp validate examples/01-echo/workflow.ts --env examples/01-echo/environment.ts
```

Compile Fluent/TS to a portable JSON manifest:

```bash
ecp compile examples/01-echo/workflow.ts -o /tmp/workflow.json
```

## Minimal Fluent workflow

```ts
import { workflow, step } from "@executioncontrolprotocol/core"

export default workflow("Echo test")
  .run([
    step("@executioncontrolprotocol/test.echo", "Echo")
      .with({ value: "hello from fluent API" })
      .as("echo"),
  ])
```

## Minimal Node environment

```ts
import { environment, extension } from "@executioncontrolprotocol/node"
import "@executioncontrolprotocol/core/testing"

export default (await environment("dev")).withExtensions([
  extension("@executioncontrolprotocol/test").with({}),
])
```

Operational APIs live on the instance returned by `init()`:

```ts
const ecp = await env.init()
await ecp.run(manifest)
await ecp.terminate()
```

## Prefer the browser?

Open the [hosted Graph Editor](https://executioncontrolprotocol.github.io/browser-demo/) or follow [Browser demo](/getting-started/browser-demo). For local Ollama, run `ecp up` so the demo can pair with a loopback bridge.
