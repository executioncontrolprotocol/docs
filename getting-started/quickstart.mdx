# Quickstart

Get ECP (Execution Control Protocol) running in a few minutes: install the CLI, add the agent skill, and run a workflow file.

## Prerequisites

- Node.js 22+
- npm

## Install

```bash
npm install -g @executioncontrolprotocol/cli
npx skills add executioncontrolprotocol/docs
```

The field-test is **0.50.0** on `latest` (not 1.0). Contributors who are changing packages can [build from source](/getting-started/build-from-source).

Confirm the binary:

```bash
ecp --help
```

## Author and run

Scaffold a workflow, or copy the echo example from the [monorepo](https://github.com/executioncontrolprotocol/executioncontrolprotocol/tree/development/examples/01-echo):

```ts
import { workflow, step } from "@executioncontrolprotocol/core"

export default workflow("Echo test").run([
  step("@executioncontrolprotocol/test.echo", "Echo")
    .with({ value: "hello from fluent API" })
    .as("echo"),
])
```

`--env` is optional. Omit it to use the process host (built-in Node plus installed plugins):

```bash
ecp workflows init brief
ecp workflows validate brief.ecp.ts --json
ecp run brief.ecp.ts --json
```

`--json` prints `{ ok: true, data }` or `{ ok: false, error: { code, message, path, suggestions } }`. Journals land under `.ecp/runs/<runId>/`.

Install a plugin when a workflow needs one:

```bash
ecp plugins install jsonata
```

Third-party plugins ask for approval. First-party npm packages install without a prompt.
