This page takes you from a bare machine to a validated, recorded run of an ECP (Execution Control Protocol) execution, with a plugin configured and a secret stored. You need about ten minutes.

<Tip>
  Using Claude Code, Cursor, or another coding agent? [Let it do this for you](/getting-started/agents) with one prompt.
</Tip>

## Install Node.js

ECP needs **Node.js 22.12 or later**. Install the current LTS release; ECP works on Node.js 22, 24, and 26. Check what you have:

```bash
node --version
```

If it's missing or older, install it:

<Tabs>
  <Tab title="macOS and Linux">
    Use [nvm](https://github.com/nvm-sh/nvm), which needs no admin rights and keeps global npm installs working:

    ```bash
    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.41.0/install.sh | bash
    export NVM_DIR="$HOME/.nvm"; . "$NVM_DIR/nvm.sh"
    nvm install --lts
    nvm alias default 'lts/*'
    ```
  </Tab>
  <Tab title="Windows">
    In PowerShell:

    ```powershell
    winget install --id OpenJS.NodeJS.LTS -e
    ```

    Then open a new terminal so `node` and `npm` are on your `PATH`.
  </Tab>
  <Tab title="Other">
    Use an installer or package manager from [nodejs.org/en/download](https://nodejs.org/en/download), or `brew install node` with Homebrew.
  </Tab>
</Tabs>

## Install the CLI

```bash
npm install -g @executioncontrolprotocol/cli
ecp --version
```

<Note>
  Until the realigned CLI is published to npm, [build from source](/getting-started/build-from-source) and link the `ecp` binary instead. Every command on this page is the same either way.
</Note>

## Add the agent skills

The ECP skills teach coding agents (Claude Code, Cursor, Windsurf, Codex, and others) how to set up, write, and run executions. Install them from this site:

```bash
npx skills add https://executioncontrolprotocol.io -g -y
```

Refresh them later with `npx skills update`. See [Set up with an AI agent](/getting-started/agents#the-ecp-skills).

## Check what is installed

The core plugin ships with the host, so a fresh install already has two capabilities: `core.transform` (a sandboxed JavaScript transform) and `core.parse-csv`.

```bash
ecp plugins
```

```text
host: started http://127.0.0.1:36169 (idle 15m)
package                         version  source  manifest
@executioncontrolprotocol/core  0.60.0   core    ok
```

The first command that needs the host starts it in the background. It stops on its own after 15 idle minutes. See [Run the host](/guides/host).

## Write an execution

Save this as `titles.ecp.json`. It takes a list of titles as run input, turns each into a URL slug with a transform step, and returns the slugs.

```json titles.ecp.json
{
  "schema": "@executioncontrolprotocol.execution",
  "version": "2.0",
  "execution": {
    "id": "slug-titles",
    "accepts": {
      "type": "object",
      "properties": { "titles": { "type": "array", "items": { "type": "string" } } },
      "required": ["titles"]
    },
    "returns": {
      "type": "object",
      "properties": { "slugs": { "type": "array" } }
    }
  },
  "steps": [
    {
      "type": "loop",
      "mode": "forEach",
      "id": "each-title",
      "ref": "state.titles",
      "as": "title",
      "steps": [
        {
          "id": "slugify",
          "uses": "@executioncontrolprotocol/core.transform",
          "accepts": { "type": "object", "properties": { "title": { "type": "string" } }, "required": ["title"] },
          "returns": { "type": "object", "properties": { "slug": { "type": "string" } }, "required": ["slug"] },
          "input": { "title": { "$ref": "state.title" } },
          "script": {
            "lang": "js",
            "source": "return { slug: input.title.toLowerCase().replace(/[^a-z0-9]+/g, '-').replace(/(^-|-$)/g, '') }"
          },
          "as": "item"
        }
      ],
      "collect": "state.item.slug",
      "into": "slugs"
    }
  ]
}
```

## Validate it

```bash
ecp execute titles.ecp.json --validate
```

```text
valid
```

Validation checks structure, each step's input against its schema, every `$ref`, and types along the data flow. Try breaking it: change `state.item.slug` to `state.item.slugg` and validate again. You get the JSON path of the problem, an error code, and the exit code `2`.

## Run it

```bash
ecp execute titles.ecp.json --input '{"titles": ["Hello World", "ECP: Execution Control Protocol"]}'
```

```text
slugify  completed
slugify  completed
{
  "slugs": [
    "hello-world",
    "ecp-execution-control-protocol"
  ]
}
```

Add `--json` to any command for a machine-readable envelope: `{ "ok": true, "data": ... }` or `{ "ok": false, "error": { "code", "message", "path", "issues", "suggestions" } }`.

## Add a plugin with a config and a secret

Most real executions call plugins. Install the JSONata transform plugin; it needs no configuration:

```bash
ecp plugins install jsonata
```

Plugins that call an external service read their settings from a **config object**, and their credentials from your OS keychain. For example, to call Claude models, install the Anthropic plugin and save a config that refers to a secret by name:

```bash
ecp plugins install anthropic
```

```json anthropic.default.json
{
  "schema": "@executioncontrolprotocol.config",
  "version": "1.0",
  "id": "anthropic/default",
  "plugin": "@executioncontrolprotocol/anthropic",
  "values": {
    "model": "claude-sonnet-4-5",
    "apiKey": { "$secret": "anthropic.apiKey" }
  }
}
```

```bash
ecp commit --type config --action create --object @anthropic.default.json
ecp config secrets set anthropic.apiKey
```

The last command asks for the key at a hidden prompt and stores it in your keychain. Any step that uses an Anthropic capability now gets the `anthropic/default` config, with the key filled in at run time and redacted everywhere it's recorded. See [Configs and secrets](/guides/configs-and-secrets).

## Inspect the run

Every run is recorded. List recent runs, then open one with its step records:

```bash
ecp retrieve --type run --limit 5
ecp retrieve --type run --id <runId> --include steps
```

## Save it

Saved executions can be run by id from anywhere, including MCP clients and the App:

```bash
ecp commit --type execution --action create --object @titles.ecp.json
ecp execute slug-titles --input '{"titles": ["Saved and reusable"]}'
```
