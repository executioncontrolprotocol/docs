# Claude Code

```bash
npx skills add executioncontrolprotocol/docs
```

Point Claude Code at a project that has the `ecp` CLI on `PATH` (global `@next` when it exists, or a [source build](/getting-started/build-from-source)). The skill teaches the loop: `search` → author `*.ecp.ts` → `validate --json` → `run --json` → `runs show` → `runs rerun --from`.

`ecp mcp serve` is a Phase 7 surface. Use the CLI until then.
