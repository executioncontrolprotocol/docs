Claude Code can help you write **Context** manifests and **`ecp`** commands. You can start with the docs skill alone; clone the repo only when you need the examples tree on disk.

## Install the docs skill

```bash
npm install -g @anthropic-ai/claude-code
npm install -g skills
skills add https://executioncontrolprotocol.io
```

## Use it in your project

Open the folder where you keep Context YAML (or any app repo). Ask Claude Code to draft manifests, suggest **`ecp validate`** / **`ecp run`** lines, or explain policies. When behavior must match the site, refer to the installed skill.

## Optional: work inside the ECP repo

Clone **[executioncontrolprotocol](https://github.com/executioncontrolprotocol/executioncontrolprotocol)** when you want to edit **`examples/`**, **`spec.yaml`**, or core packages. Then run **`npm install`**, **`npm run build`**, and use **`ecp`** via **`npx`** or **`npm link`** as described in [Build from source](/getting-started/build-from-source).
