Claude Code can drive ECP (Execution Control Protocol) two ways: through the `ecp` CLI in its terminal, guided by the ECP skill, or through the three MCP tools. Set up both; Claude uses whichever fits the task.

## Add the skills

```bash
npx skills add https://executioncontrolprotocol.io -g -y
```

The `ecp-setup` skill installs and configures ECP; the `ecp` skill teaches the loop: retrieve capabilities, write an `*.ecp.json` file, validate with `--json`, fix issues by path and code, run, inspect the run, and commit. It also tells Claude when to stop and ask you, for example before installing a third-party plugin or when a secret is missing.

To have the agent install Node.js, the CLI, examples, and plugins for you, see [Set up with an AI agent](/getting-started/agents).

## Connect MCP

```bash
claude mcp add ecp -- ecp mcp start
```

Claude then has `retrieve`, `execute`, and `commit` as tools. See [Connect over MCP](/guides/mcp).

## Try it

Ask Claude something like:

> Write an ECP execution that reads `data/orders.csv`, keeps rows where status is "open", and returns their ids. Validate it, run it, and save it as `open-orders`.

Keep `ecp app open-orders.ecp.json` open in a browser to watch the graph update as Claude edits the file.
