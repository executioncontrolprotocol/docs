# Cursor

Use Cursor to author ECP (Execution Control Protocol) Fluent workflows, environments, and CLI commands.

## Install the ECP skill

```bash
npm install -g skills
npx skills add https://executioncontrolprotocol.io
```

The skill teaches Workflow vs Environment, Fluent authoring, and current CLI commands — not legacy YAML Context manifests.

## Prompt tips

Ask Cursor to:

- Write a `workflow(...).run([step(...).as(...)])` module
- Bind an environment with `extension("…").with({})` after importing catalog packages
- Use `ecp run` / `validate` / `compile` with `--env`
- Keep secrets out of workflows

Point it at [Fluent API](/guides/fluent-api) and [Concepts](/learn/concepts) when generating code.
