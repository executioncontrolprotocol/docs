Cursor can help you write **Context** manifests, run **`ecp`** commands, and learn the spec. Pick the path that matches how you work.

## Docs skill (fastest)

You do **not** need a clone of the ECP repo for this step.

1. Install the Skills CLI:

```bash
npm install -g skills
```

2. Add the live documentation skill:

```bash
skills add https://executioncontrolprotocol.io
```

3. In Cursor, use the agent as usual. When something should match the public docs, ask it to follow the ECP skill.

This is the quickest way to get accurate answers about **CLI usage**, **concepts**, and **security** without opening the reference manually.

## Cursor Rules (project rules)

**Cursor Rules** are markdown or MDC files Cursor loads so the assistant follows your team’s conventions. ECP’s own engineering rules live in the main repository under **`.cursor/rules/`**:

**[Browse `.cursor/rules` on GitHub](https://github.com/executioncontrolprotocol/executioncontrolprotocol/tree/main/.cursor/rules)**

### If you contribute to the ECP core repo

Clone **[executioncontrolprotocol](https://github.com/executioncontrolprotocol/executioncontrolprotocol)** and open it in Cursor. The repo already includes rules for TypeScript, the spec, CLI patterns, and tests. Use them as-is so patches match project standards.

### If you only author Contexts in your app repo

Create a **`.cursor/rules/`** folder in **your** project and add a short rule file (for example **`ecp-context.mdc`**) that tells the agent to:

- Prefer manifests that validate with **`ecp validate`**
- Respect **inputs**, **schemas**, **policies**, and **mounts** as described on [executioncontrolprotocol.io](https://executioncontrolprotocol.io)
- Suggest **`ecp run`** / **`ecp validate`** command lines and to use **`ecp --help`** when unsure

You can paste or summarize points from the [Quickstart](/getting-started/quickstart), [Concepts](/learn/concepts), and [Security](/learn/security) pages into that file so offline edits stay aligned with the public spec.

## Day-to-day prompts

- “Generate a minimal `context.yaml` with one executor, one input, and default-deny tool access.”
- “Given this manifest, what `ecp validate` and `ecp run` commands should I use with OpenAI?”
- “Review this Context against ECP security guidance.”

When flags or defaults are unclear, prefer **`ecp --help`** and **`ecp run --help`** (and the same for other subcommands) so you match your installed CLI.
