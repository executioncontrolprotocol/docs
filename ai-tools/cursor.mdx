Cursor's agent can write and run ECP (Execution Control Protocol) executions through the `ecp` CLI or the three MCP tools.

## Add the skill

```bash
npx skills add executioncontrolprotocol/docs
```

## Connect MCP

Add the relay to `.cursor/mcp.json` in your project:

```json .cursor/mcp.json
{
  "mcpServers": {
    "ecp": {
      "command": "ecp",
      "args": ["mcp", "start"]
    }
  }
}
```

The agent gets `retrieve`, `execute`, and `commit`. See [Connect over MCP](/guides/mcp).

## Editor support

Add a `$schema` line to your executions for autocomplete and inline errors from your installed capabilities:

```bash
ecp retrieve --type schema
```

```json
{ "$schema": "file:///home/you/.ecp/schema/execution.schema.json", "schema": "@executioncontrolprotocol.execution", "version": "2.0", "steps": [] }
```
