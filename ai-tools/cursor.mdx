# Cursor

Install the consumer skill so Cursor can author and repair ECP (Execution Control Protocol) workflow files:

```bash
npx skills add executioncontrolprotocol/docs
```

The skill lives at `skills/ecp/` in this docs repository. After install, ask the agent to search capabilities, write a `*.ecp.ts` file, validate with `--json`, and run.

`--env` is optional. Do not put secret values in the workflow file. Learn flags from `ecp <command> --help`.

To drive the same host from MCP, run `ecp mcp serve` (see [MCP](/guides/mcp)). The CLI remains the primary surface.
