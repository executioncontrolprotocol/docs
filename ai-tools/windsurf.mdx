# Windsurf

```bash
npx skills add executioncontrolprotocol/docs
```

Install the CLI, then let the agent operate `ecp` from the terminal. Workflow files are ordinary TypeScript the editor can typecheck once `@executioncontrolprotocol/core` is a dependency.

MCP integration waits on Phase 7.
