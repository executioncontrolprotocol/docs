Windsurf's agent can write and run ECP (Execution Control Protocol) executions through the `ecp` CLI or the three MCP tools.

## Add the skill

```bash
npx skills add executioncontrolprotocol/docs
```

## Connect MCP

Add the relay to Windsurf's MCP configuration (`~/.codeium/windsurf/mcp_config.json`):

```json
{
  "mcpServers": {
    "ecp": {
      "command": "ecp",
      "args": ["mcp", "start"]
    }
  }
}
```

See [Connect over MCP](/guides/mcp) for the tools and how a session goes.
