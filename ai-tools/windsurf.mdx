Windsurf’s Cascade assistant can help with **Context** manifests and **`ecp`** usage. Install the skill first; clone the main repo only when you need files from **`examples/`** locally.

## Install the docs skill

```bash
npm install -g skills
skills add https://executioncontrolprotocol.io
```

## Use Cascade

Open your project in Windsurf. Use Cascade to edit manifests, propose **`ecp run`** and **`ecp validate`** commands, and answer questions using the public docs.

## Optional: open the ECP repository

Clone **[executioncontrolprotocol](https://github.com/executioncontrolprotocol/executioncontrolprotocol)** if you are changing examples or the core implementation. Build and test flows live in [Build from source](/getting-started/build-from-source).
