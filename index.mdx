ECP (Execution Control Protocol) is an open standard and reference implementation for defining, packaging, and running **portable workflows** inside **governed environments**.

- **MCP** standardizes how models call tools.
- **ECP** standardizes how agents, tools, policies, and runtimes execute together.

You author workflows with a **Fluent TypeScript API**, compile them to JSON manifests, and run them with the `ecp` CLI or a host runtime (Node or browser).

## What you build

| Piece | Role |
| ----- | ---- |
| **Workflow** | Portable graph of steps (Fluent/TS or JSON) |
| **Environment** | Runtime + extensions + policies that can execute a workflow |
| **Ecp** | Operational instance after `env.init()` — run, validate, encode, decode, patch, describe, search |
