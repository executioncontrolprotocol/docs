---
title: "Execution Control Protocol"
description: "Define and run governed agent execution environments on top of MCP"
---

**ECP (Execution Control Protocol)** is an open way to describe **how agents run**: what they can see, which **MCP** tools they may use, and which **policies** apply. You ship a **Context** manifest; a host loads it, enforces **security**, and runs the same spec in development or production.

- **MCP** defines how models call tools.
- **ECP** defines how agents, tools, context, and policies execute together.

## Get running in minutes

Install the CLI from npm, create a small config, and validate or run a sample Context. No clone required.
