# JSONata transform

Pick names from a list with a JSONata expression instead of JavaScript.

Shows: `jsonata.transform`, `expression`.

Run the commands below from this folder (`ecp-examples/jsonata-names`).

## Set up

```bash
ecp plugins install jsonata
```

## Run

```bash
ecp execute names.ecp.json --input '{}'
```

Generated from `examples/catalog.json` for ECP 0.60.0. Do not edit by hand.
