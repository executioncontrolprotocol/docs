# Changelog

The reset ships as **1.0**, a major version. There is no compatibility shim for 0.x APIs. Phase 9 will `npm deprecate` old packages when first-party npm exists.

## 1.0 (reset, in progress)

- CLI rebuilt on oclif 5 with generated commands from `defineOperation` and plugin metadata.
- Workflow files are `*.ecp.ts`; `--env` is optional.
- Bindings compile to `@executioncontrolprotocol.requirements`, not into the portable manifest.
- Run journals under `.ecp/runs/<runId>/`; `ecp runs list|show|resume|rerun`.
- Plugins live in `plugins/plugin-*` with Changesets (`1.0.0-next.0`).
- Types live at `@executioncontrolprotocol/core/types`.

## Removed

- Harnesses, evals, browser demo, Temporal stub
- `format-eql`, `chrome-ai`, `memory`, `telemetry`, `storage`, `slack`, `browser-secrets`, `image-policy`
- CLI `serve`, `up`, `encode`, `decode` as root commands
- `ecp test` (replaced by `ecp run --to` and `ecp runs`)
- YAML Context / `ECPContext` / `spec.yaml`

## Not yet in 1.0 docs

MCP (Phase 7) and the App (Phase 8) have [placeholder](/guides/mcp) pages only.
