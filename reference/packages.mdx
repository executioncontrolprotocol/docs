ECP (Execution Control Protocol) is a set of packages under the `@executioncontrolprotocol` npm scope. Most people only install the CLI, which brings the host, the MCP relay, and the App with it. Plugin authors also use the plugin SDK.

| Package | Role |
| ------- | ---- |
| `@executioncontrolprotocol/cli` | The `ecp` command. Install this one. |
| `@executioncontrolprotocol/host` | The host process, HTTP API, and supervisor |
| `@executioncontrolprotocol/engine` | Validation, the executor, operations, and the service container |
| `@executioncontrolprotocol/protocol` | Types, JSON Schemas, service tokens, and the error catalogue |
| `@executioncontrolprotocol/local` | Local services: disk storage, OS keychain secrets, plugin loading |
| `@executioncontrolprotocol/quickjs` | The sandboxed expression and script engine |
| `@executioncontrolprotocol/formatters` | JSON and TOON output formatters |
| `@executioncontrolprotocol/mcp-relay` | The stdio MCP server behind `ecp mcp start` |
| `@executioncontrolprotocol/app` | The visual App served by the host |
| `@executioncontrolprotocol/plugin-sdk` | `definePlugin`, `capability`, `fileRefSchema`, and `ecp-plugin-manifest` |

Plugins are separate packages; the plugin id is the package name, such as `@executioncontrolprotocol/jsonata`. See [Plugins](/reference/plugins).

## Requirements

- Node.js 22.12 or later
- macOS, Linux, or Windows

## Install

```bash
npm install -g @executioncontrolprotocol/cli
```

For plugin development:

```bash
npm install --save-dev @executioncontrolprotocol/plugin-sdk zod typescript
```

To work on ECP itself, [build from source](/getting-started/build-from-source).
