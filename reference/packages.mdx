# Packages

Scope: `@executioncontrolprotocol/*`. The CLI reset field-test is **0.51.0** on npm `latest` (not 1.0). Versions below match the monorepo `package.json` values on `development`.

## Host-agnostic and hosts

| Package | Role | Version |
| ------- | ---- | ------- |
| `@executioncontrolprotocol/core` | Fluent API, engine, `./types` | `0.51.0` |
| `@executioncontrolprotocol/node` | Node host, compile, loaders, journals | `0.51.0` |
| `@executioncontrolprotocol/browser` | Browser host, esbuild-wasm compile | `0.51.0` |
| `@executioncontrolprotocol/cli` | `ecp` CLI (oclif 5) | `0.51.0` |
| `@executioncontrolprotocol/plugin-sdk` | `toCommands`, `defineOperation` | `0.51.0` |
| `@executioncontrolprotocol/mcp` | MCP server + `ecp mcp serve` | `0.51.0` |
| `@executioncontrolprotocol/app` | Visual App library, graph encoder, `dist/web` | `0.51.0` |
| `@executioncontrolprotocol/plugin-app` | JIT plugin behind `ecp app` | `0.51.0` |

## Plugins

Every first-party plugin lives under `plugins/plugin-*` at `0.51.0` (Changesets independent versioning). See the [plugin catalogue](/reference/plugins).

Ids such as `@executioncontrolprotocol/jsonata` are protocol ids, not always npm names. npm names use the `plugin-` prefix.

## Install

```bash
npm install -g @executioncontrolprotocol/cli
```

Contributors who are changing packages can [build from source](/getting-started/build-from-source).
