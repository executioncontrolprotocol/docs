# Packages

Scope: `@executioncontrolprotocol/*`. During the CLI reset, first-party npm is unpublished; versions below are the monorepo `package.json` values on `milestone/cli-reset`.

## Host-agnostic and hosts

| Package | Role | Version |
| ------- | ---- | ------- |
| `@executioncontrolprotocol/core` | Fluent API, engine, `./types` | `1.0.0-next.0` |
| `@executioncontrolprotocol/node` | Node host, compile, loaders, journals | `1.0.0-next.0` |
| `@executioncontrolprotocol/browser` | Browser host, esbuild-wasm compile | `1.0.0-next.0` |
| `@executioncontrolprotocol/cli` | `ecp` CLI (oclif 5) | `1.0.0-next.0` |
| `@executioncontrolprotocol/plugin-sdk` | `toCommands`, `defineOperation` | `1.0.0-next.0` |
| `@executioncontrolprotocol/mcp` | MCP server + `ecp mcp serve` | `1.0.0-next.0` |

The visual App is `packages/app` in Phase 8 (not published yet).

## Plugins

Every first-party plugin lives under `plugins/plugin-*` at `1.0.0-next.0` (Changesets independent versioning). See the [plugin catalogue](/reference/plugins).

Ids such as `@executioncontrolprotocol/jsonata` are protocol ids, not always npm names. npm names use the `plugin-` prefix.

## Install

```bash
npm install -g @executioncontrolprotocol/cli@next
```

Until `@next` exists, [build from source](/getting-started/build-from-source).
