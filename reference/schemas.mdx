# Schemas

ECP (Execution Control Protocol) publishes JSON Schema for the documents you persist.

Generate them from the monorepo with `pnpm run generate:schema`. Output: `packages/core/dist/schemas`.

| Schema | Document |
| ------ | -------- |
| `@executioncontrolprotocol.workflow` | Portable workflow manifest (`version: "1.0"`) |
| `@executioncontrolprotocol.requirements` | Workflow-file bindings (never merged into the manifest) |
| `@executioncontrolprotocol.run.journal` | Run journal (`journalVersion: 1`) |
| `@executioncontrolprotocol.environment` | Environment overlay |

Validation issues carry `code`, `message`, `path`, `suggestions`, and `severity`. New codes join the `ECP_*` catalogue in [Error codes](/reference/error-codes).

Do not use the removed v0.5 YAML Context / `spec.yaml` model.
