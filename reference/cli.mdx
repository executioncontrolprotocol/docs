Every `ecp` command, generated from the CLI itself. Run `ecp <command> --help` for the same information in your terminal.

Every command except `ecp mcp start` accepts `--json` and prints one envelope on stdout: `{ ok: true, data }` on success or `{ ok: false, error }` on failure. See [Operations](/reference/operations) for the shapes.

| Exit code | Meaning |
| --- | --- |
| `0` | Success, including a valid validation and a completed run |
| `1` | The run failed or was cancelled, or an internal error |
| `2` | Invalid request or execution |
| `3` | A required plugin is missing |
| `4` | Host unavailable or unauthorized |

See [Error codes](/reference/error-codes) for every code.

## Operations

### `ecp retrieve`

Read capabilities, executions, configs, runs, plugins, formatters, or editor schema files; use execute to run and commit to write.

#### Usage

```bash
ecp retrieve [FLAGS]
```

#### Flags

| Flag | Type | Default | Allowed options | Description |
| --- | --- | --- | --- | --- |
| `--filter` | option | — | — | Narrow a list with key=value (repeatable): plugin, executionId, status, clientRequestId; e.g. status=failed. |
| `--format` | option | — | — | Formatter id when --type formatter. |
| `--id` | option | — | — | Fetch one item by id instead of listing. |
| `--include` | option | — | — | Comma-separated extras: run detail (steps, events, manifest, state) or schema document with --type schema. |
| `--json` | boolean | — | — | Print one JSON object on stdout: \{ ok: true, data } on success, \{ ok: false, error } on failure (exit code non-zero). |
| `--limit` | option | — | — | Maximum rows to return (default 10, max 100). |
| `--no-start-host` | boolean | — | — | Do not start a background host when one is not already running. |
| `--out` | option | — | — | Write full JSON result to this file and print a one-line summary. |
| `--query` | option | — | — | Fuzzy search string when listing capabilities or executions. |
| `--type` | option | — | capability, execution, config, run, plugin, formatter, schema | What to list or fetch (capability, execution, config, run, plugin, formatter, schema). |

#### Examples

```bash
# Lists matching capabilities as a table; add --json for the operation envelope.
ecp retrieve --type capability --query echo
# Prints the root editor schema path (no host auto-start).
ecp retrieve --type schema
# Inlines the root schema JSON when under the size cap.
ecp retrieve --type schema --include document
# Writes a large plugin schema to a file.
ecp retrieve --type schema --id @executioncontrolprotocol/adobe-firefly-services --include document --out firefly.schema.json
```
