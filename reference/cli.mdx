# CLI

This page is a stub. The full catalogue is generated from oclif manifests in the ECP checkout (`packages/cli` and `plugins/plugin-*`).

Until that generator lands, use:

```bash
ecp --help
ecp <command> --help
```

Primary commands after the reset:

| Command | Role |
| ------- | ---- |
| `ecp run <file>` | Run a workflow (`--env` optional, `--to`, `--events`, `--json`) |
| `ecp validate <file>` | Validate a workflow |
| `ecp describe` | Catalog capabilities |
| `ecp search <query>` | Fuzzy-search capabilities |
| `ecp invoke` | Invoke one capability |
| `ecp runs list \| show \| resume \| rerun` | Journals |
| `ecp install <file>` | Install requirements |
| `ecp init <name>` | Scaffold a workflow |
| `ecp plugins new \| link \| install \| build \| check` | Plugin lifecycle |

`--json` prints `{ ok: true, data }` or `{ ok: false, error: { code, message, path, suggestions } }`.

There is no `ecp test`, `ecp serve`, `ecp up`, or root `ecp encode` / `ecp decode`. Format plugins expose `ecp format-toon encode` (and similar).
