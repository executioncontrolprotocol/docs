# CLI reference

The `ecp` CLI runs **workflows** in configured **environments** on Node.js.

## Install

```bash
npm install -g @executioncontrolprotocol/cli
```

From a monorepo build: `npm link` inside `packages/cli` after `npm run build`. See [Build from source](/getting-started/build-from-source).

## Commands

### `ecp run`

```bash
ecp run examples/01-echo/workflow.ts --env examples/01-echo/environment.ts
ecp run workflow.json --env environment.ts --input input.json
ecp run workflow.ts --env environment.ts --dry-run
```

| Flag | Role |
| ---- | ---- |
| `--env` | Environment module (default export) |
| `--input` | JSON input file |
| `--dry-run` | Validate/plan without invoking capabilities |

### `ecp validate`

```bash
ecp validate examples/01-echo/workflow.ts --env examples/01-echo/environment.ts
```

### `ecp compile`

Compile Fluent/TS (or JS) workflow source to portable JSON. No `--env` required.

```bash
ecp compile examples/01-echo/workflow.ts -o dist/workflow.json
```

### `ecp describe` / `ecp search`

```bash
ecp describe --env examples/01-echo/environment.ts
ecp search "echo" --env examples/01-echo/environment.ts
```

Optional `--query` on describe where supported by your CLI build.

### `ecp encode` / `ecp decode`

Require an environment that binds the format extension you use.

```bash
ecp encode workflow.json --format toon --env environment.ts -o workflow.toon
ecp encode workflow.json --format fluent --env environment.ts -o workflow.generated.ts
ecp decode workflow.toon --format toon --env environment.ts -o workflow.json
```

Fluent decode is not supported — use `ecp compile` instead. JSON is the canonical manifest format.

### `ecp up`

Start a loopback HTTP daemon that bridges Ollama for the [browser demo](/getting-started/browser-demo) (CORS + Private Network Access), then open the demo with a pairing token:

```bash
ecp up
# Opens https://executioncontrolprotocol.github.io/browser-demo/?token=<uuid>&bridge=http://127.0.0.1:3090

ecp up --open-url http://localhost:5173/
ecp up --no-open
```

- Default port **3090**
- `GET /health` — `{ ok, version, ollamaReachable }` (no auth)
- `POST /v1/invoke` — Bearer token; body `{ capability, input?, provider? }`

Hosted HTTPS demos need Chromium for Private Network Access. Add origins with `--cors-origin` when needed.

### `ecp config secrets`

OS keychain helpers:

```bash
ecp config secrets add KEY
ecp config secrets list
ecp config secrets get KEY
ecp config secrets remove KEY
```
