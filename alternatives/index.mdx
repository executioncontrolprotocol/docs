title: "Alternatives"
description: "How ECP (Execution Control Protocol) compares with agent frameworks, workflow engines, and MCP-only setups, and when to use each."
---

ECP (Execution Control Protocol) is a **deterministic delegation** layer: an agent writes a JSON execution, a local host validates and runs it, and the run is recorded. It is not an agent harness, and it doesn't replace MCP.

| You need | Reach for |
| -------- | --------- |
| A repeatable graph an agent can write, check, run, and repair | ECP |
| A model calling one tool at a time | [MCP](/learn/relationship-to-mcp) |
| A library for building an LLM application in code | [LangChain](/alternatives/ecp-vs-langchain) and similar frameworks |
| A personal assistant with connectors and a chat UI | [OpenClaw](/alternatives/ecp-vs-openclaw) and similar products |

These aren't exclusive. An app built with a framework, or a personal assistant, can hand repeatable work to ECP over MCP or the CLI.
