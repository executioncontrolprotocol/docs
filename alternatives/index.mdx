# Alternatives

ECP (Execution Control Protocol) is a **deterministic delegation** layer. It is not a full agent harness and not a replacement for MCP.

Pick ECP when you need a portable workflow graph, structured errors, journals, and plugins you can install from npm. Pick a framework when you want batteries-included chains, memory, and UI as one product.

| Need | Reach for |
| ---- | --------- |
| Governed, repairable graphs an agent authors | ECP |
| Model-to-tool RPC | MCP |
| Opinionated chains and RAG in one library | [LangChain](/alternatives/ecp-vs-langchain) |
| Personal-agent product with connectors | [OpenClaw](/alternatives/ecp-vs-openclaw) |
