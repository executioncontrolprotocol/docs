# ECP vs OpenClaw

OpenClaw-style products emphasize an integrated agent experience. ECP (Execution Control Protocol) emphasizes **portable workflows**, **host environments**, and **explicit control**.

| Concern | Typical framework product | ECP |
| ------- | ------------------------- | --- |
| Portability | Tied to the product | Workflow manifests move across hosts |
| Permissions | Product defaults | Environment policies + capability allowlists |
| Secrets | Product storage | Host keychain / browser vault — not in workflows |
| Discovery | Product UI | `describe` / `search` on an `Ecp` |
| Authoring | Product-specific | Fluent API + JSON (+ TOON encode) |

You can use a product UI for day-to-day chat and still adopt ECP when you need shareable execution environments, CLI determinism, or MCP-exposed ops.
