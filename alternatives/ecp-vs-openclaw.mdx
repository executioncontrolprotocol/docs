# ECP vs OpenClaw

OpenClaw-style products are **personal agents** with connectors and a chat UI. ECP (Execution Control Protocol) is the delegation capability those products (or any harness) can call.

## Positioning

| | Personal-agent product | ECP |
| --- | --- | --- |
| Surface | Chat, connectors, memory | CLI, workflow files, journals |
| Scope | The whole harness | One capability inside a harness |
| Replay | Session history | `ecp runs show` / `rerun --from` |

Use the product when you want an assistant. Use ECP when the assistant should hand off a **repeatable, policy-bound** graph instead of re-prompting.
