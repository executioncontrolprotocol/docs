---
title: "ECP vs OpenClaw"
description: "When to use ECP (Execution Control Protocol) instead of, or inside, a personal-agent product like OpenClaw."
---

OpenClaw-style products are **personal agents**: a chat interface, connectors, and memory in one package. ECP (Execution Control Protocol) is a **delegation layer** that any agent, including a personal one, can use to hand off repeatable work.

| | Personal-agent product | ECP |
| --- | --- | --- |
| Surface | Chat, connectors, memory | CLI, MCP tools, HTTP API, and a graph App |
| Scope | The whole assistant | One capability an assistant uses |
| Repeating a task | The model plans it again | Run the saved execution by id |
| Record | Conversation history | Run records with each step's input, output, and error |

Use the product when you want an assistant. Give that assistant ECP when it should stop re-planning the same task and run a checked, recorded execution instead.
